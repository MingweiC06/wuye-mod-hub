# 云服务器选型与上线路线（面向中国大陆访问）

> 本项目是单进程 Node + SQLite 的小站，1 核 1G 也能跑，但为了留出余量和
> 后续做视频/图片，建议 **2 核 2G**。以下价格为 2026 年常见活动价区间，下单前
> 以官网为准。

## 1. 推荐配置

| 项目 | 建议 | 说明 |
| --- | --- | --- |
| CPU / 内存 | 2 核 / 2 GB | 1 核 1G 可跑但编译、备份、突发流量会紧张 |
| 系统盘 | 40–60 GB SSD | 数据库 + 日志 + 备份，够用很久 |
| 带宽 | 3–5 Mbps 峰值 | 页面本身很轻（< 400 KB），主要看视频外链 |
| 地域 | 离你主要粉丝近的国内地域 | 华东/华北/华南均可，备案主体在哪就选哪 |
| 系统 | Ubuntu 24.04 LTS | 与 `deploy/README.md` 完全对应 |
| 快照/备份 | 开启自动快照 | 云厂商快照 + 项目自带 `npm run backup` 双保险 |

## 2. 阿里云 vs 腾讯云（轻量应用服务器）

两者都适合，选有活动、离你近的即可：

| 对比项 | 阿里云轻量应用服务器 | 腾讯云轻量应用服务器 |
| --- | --- | --- |
| 入门价 | 2C2G 常见 ¥60–120/年（新用户活动） | 2C2G 常见 ¥50–110/年（新用户活动） |
| 控制台 | 功能全，文档多 | 更简洁，微信生态方便 |
| 备案 | 阿里云备案系统成熟 | 腾讯云备案同样成熟 |
| 防火墙 | 控制台「防火墙」放行 80/443/22 | 控制台「防火墙」放行 80/443/22 |
| 适合 | 想省心、后续可能上其它云产品 | 已有腾讯云账号/微信支付方便 |

**结论**：没有偏好就选当前活动更便宜的一家；不要买「境外/香港」节点，国内粉丝
访问延迟高，而且无法完成 ICP 备案。

## 3. 必须先做的合规事项（中国大陆）

1. **域名实名认证**：在阿里云/腾讯云注册域名并完成实名。
2. **ICP 备案**：用云厂商的备案系统提交，通常 7–20 个工作日；备案通过前，
   域名走 80/443 会被拦截。个人备案即可，网站名称不要写「官方」等敏感词。
3. **公安备案**：ICP 备案通过后 30 日内，在「全国互联网安全管理服务平台」提交。
4. **内容合规**：站点已有敏感词过滤、审核队列、管理码；上线后仍需人工看审核队列，
   不要放盗版资源下载、外链网盘、代练/广告。

## 4. 域名与 HTTPS

- 域名后缀 `.com` / `.cn` / `.top` 均可；`.cn` 实名要求更严格。
- 证书用 Let's Encrypt（免费，`certbot` 自动续期），步骤见 `deploy/README.md`。
- 国内 CDN 不是必须：本站全部静态资源本地托管，上 CDN 反而增加备案与成本。

## 5. 上线最短路径

```bash
# 1) 买 2C2G 轻量服务器（Ubuntu 24.04），控制台防火墙放行 22/80/443
# 2) 域名解析 A 记录到服务器公网 IP
# 3) 按 deploy/README.md：
#    - 安装 Node 24
#    - 创建 wuye 用户、上传代码到 /srv/wuye-mod-hub
#    - 配置 /etc/wuye-mod-hub/wuye.env（HOST=127.0.0.1, TRUST_PROXY=1, COOKIE_SECURE=1）
#    - systemd 启动、Nginx 反代、certbot 签证书
# 4) 首次启动从日志拿管理码，登录 /admin 改码
# 5) 配置每日备份 cron，验证一次恢复
```

## 7. 不建议的做法

- 不要买「免备案香港/美国节点」硬扛：国内访问不稳定，且平台/支付合规风险高。
- 不要把 Node 的 8080 端口直接暴露公网；只让 Nginx 反代。
- 不要用 SQLite 跑多进程/多机（本项目按单实例设计），需要扩容先评估架构。
- 不要在仓库里提交 `data/`、`backups/`、`.env`（`.gitignore` 已处理）。
